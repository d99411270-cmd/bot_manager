# Память компании

Компания: Стокозавр.
Направление: оптовая продажа продуктов питания.

Клиенты: магазины, торговые точки, кафе, рестораны, предприниматели, перепродавцы.

Категории:

- бакалея;
- макаронные изделия;
- крупы;
- масло;
- консервация;
- напитки;
- сладости;
- продукты длительного хранения.

Особенности: оптовые поставки, работа с объёмами, подбор продукции под клиента.

Запрещено придумывать:

- цены;
- наличие;
- условия доставки;
- акции;
- конкретные бренды и позиции, которых нет в этой памяти.
